# Hangman (Python backend + web frontend)

## Run
    python app.py
Open http://localhost:8000  (needs Python 3.8+, no extra packages).

## Structure
- `app.py`          Backend: HTTP server + game logic + JSON API (`/api/new`, `/api/guess`)
- `static/`         Frontend: `index.html`, `style.css`, `script.js`

Concepts used: random, while/if-else logic, strings, lists, dicts, classes, HTTP/JSON.
