# PyBot - Basic Rule-Based Chatbot (Python backend + web frontend)

## Run the web app
    python app.py
Open http://localhost:8000  (Python 3.8+, no extra packages)

## Run in the console instead
    python chatbot.py

## Files
- `chatbot.py`  Chat logic: get_reply() with if-elif, functions, input loop
- `app.py`      Backend server with JSON API: POST /api/chat
- `static/`     Frontend: index.html, style.css, script.js
